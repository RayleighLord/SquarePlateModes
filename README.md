# Square Membrane Modes

[Open the interactive explorer](https://rayleighlord.github.io/SquarePlateModes/)

Explore the vibration modes of a plate with fixed boundaries interactively.

The animation uses exact relative modal-frequency scaling. The fundamental
mode completes one deliberately slow visual cycle every 10 seconds; higher
modes accelerate in proportion to `sqrt((nx^2 + ny^2) / 2)`.
